# Stack

## Topic

Stacks follow LIFO (Last In, First Out) behavior and are useful for nested structures and ordered operations.

## Common Patterns

- Matching brackets
- Monotonic stack
- Depth-first exploration
- Backtracking support

## Complexity Tips

- Push/pop operations are O(1)
- Good for undo history and nested structures
- Be careful with recursive stack usage in deep inputs

## Common Interview Questions

- Valid Parentheses
- Daily Temperatures
- Min Stack
- Largest Rectangle in Histogram
- Next Greater Element
