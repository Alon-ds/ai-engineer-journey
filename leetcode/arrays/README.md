# Arrays

## Topic

Arrays are fixed or dynamic collections of values stored in contiguous memory space. They are foundational for understanding indexing, iteration, and efficient data access.

## Common Patterns

- Two-pointer techniques
- Prefix sums
- Sliding window
- Sorting and searching
- Hashing for frequency counts

## Complexity Tips

- Access by index is O(1)
- Search in an unsorted array is O(n)
- Sorting an array is often O(n log n)
- Repeated appends and inserts can become expensive in dynamic arrays
