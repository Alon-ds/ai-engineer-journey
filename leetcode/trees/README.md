# Trees

## Topic

Trees model hierarchical relationships and are central to recursion, traversal, and balanced structures.

## Common Patterns

- DFS recursion
- BFS level order
- Tree balancing
- Path and subtree logic

## Complexity Tips

- Tree traversal is O(n)
- Recursion depth can be a problem for very tall trees
- Use iterative approaches when needed

## Common Interview Questions

- Maximum Depth of Binary Tree
- Invert Binary Tree
- Lowest Common Ancestor
- Validate Binary Search Tree
- Binary Tree Level Order Traversal
