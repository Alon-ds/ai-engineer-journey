# Dynamic Programming

## Topic

Dynamic programming optimizes recursive problem solving by reusing previously computed results.

## Common Patterns

- 1D or 2D memoization
- State transitions
- Knapsack-style decisions
- Path-counting or optimization

## Complexity Tips

- Great when subproblems overlap
- Can reduce exponential time to polynomial time
- Space complexity can be high if states are stored fully

## Common Interview Questions

- Climbing Stairs
- House Robber
- Coin Change
- Longest Increasing Subsequence
- Word Break
