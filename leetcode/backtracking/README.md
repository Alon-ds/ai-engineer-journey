# Backtracking

## Topic

Backtracking explores many possible states and abandons invalid branches when constraints are violated.

## Common Patterns

- Permutations and combinations
- Constraint satisfaction
- Recursive candidate generation
- Pruning

## Complexity Tips

- Can explode exponentially
- Pruning is critical to performance
- State management must stay clean and efficient

## Common Interview Questions

- Permutations
- Subsets
- Word Search
- N-Queens
- Combination Sum
