# Heap

## Topic

Heaps are priority queue structures that efficiently support minimum or maximum retrieval.

## Common Patterns

- Top-k tracking
- Priority scheduling
- Merge log streams
- Greedy optimization

## Complexity Tips

- Push/pop is O(log n)
- Peek is O(1)
- Good for runtime-critical ordering logic

## Common Interview Questions

- Kth Largest Element
- Top K Frequent Elements
- Merge K Sorted Lists
- Find Median from Data Stream
- Task Scheduler
