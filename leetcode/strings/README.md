# Strings

## Topic

Strings are sequences of characters and are often solved with indexing, pattern matching, and dynamic operations.

## Common Patterns

- Character frequency counting
- Sliding window
- Prefix/suffix comparisons
- Hash maps and sets
- Parsing and validation

## Complexity Tips

- String concatenation can be expensive in loops
- Reversal or substring operations may create copies
- Use efficient matching patterns when needed

## Common Interview Questions

- Longest Palindromic Substring
- Valid Anagram
- Group Anagrams
- String Compression
- Longest Substring Without Repeating Characters
