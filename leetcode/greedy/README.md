# Greedy

## Topic

Greedy algorithms make locally optimal decisions with the hope of reaching a globally optimal result.

## Common Patterns

- Interval scheduling
- Choosing largest or smallest available value
- Local optimization with proof of correctness

## Complexity Tips

- Usually efficient and easy to implement
- Proof of correctness is essential
- Not all problems are suitable for greedy logic

## Common Interview Questions

- Assign Cookies
- Jump Game
- Gas Station
- Stock Profit with One Transaction
- Partition Labels
