# Two Pointers

## Topic

The two-pointer pattern uses two indices moving through data to improve efficiency and reduce complexity.

## Common Patterns

- Left/right scan
- Sorted array pairs
- Reverse or merge operations
- Palindrome checks

## Complexity Tips

- Often reduces O(n^2) logic to O(n)
- Works well with sorted arrays or paired sequences
- Be careful with boundary conditions

## Common Interview Questions

- Valid Palindrome
- Container With Most Water
- 3Sum
- Remove Duplicates from Sorted Array
- Trapping Rain Water
