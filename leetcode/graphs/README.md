# Graphs

## Topic

Graphs model connections between entities and are key for traversal, connectivity, and optimization problems.

## Common Patterns

- BFS and DFS
- Cycle detection
- Topological sort
- Shortest path
- Union-find

## Complexity Tips

- Graph traversal is O(V + E)
- Use adjacency lists for sparse graphs
- Avoid repeated expensive traversals when possible

## Common Interview Questions

- Number of Islands
- Clone Graph
- Course Schedule
- Pacific Atlantic Water Flow
- Word Ladder
