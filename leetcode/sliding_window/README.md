# Sliding Window

## Topic

Sliding window keeps a moving range over data and updates it efficiently as the window moves.

## Common Patterns

- Fixed-size windows
- Variable-size windows
- Maximum/minimum within a range
- Prefix transformations

## Complexity Tips

- Often reduces nested loops to O(n)
- Need to maintain a window state and update it carefully
- Great fit for array/string problems

## Common Interview Questions

- Longest Substring Without Repeating Characters
- Maximum Average Subarray
- Minimum Size Subarray Sum
- Best Time to Buy and Sell Stock II
- Permutation in String
