# Binary Search

## Topic

Binary search reduces search space by half at each step in sorted data.

## Common Patterns

- Search in sorted arrays
- Lower bound / upper bound
- Monotonic predicate search
- Search on answer

## Complexity Tips

- O(log n) time
- Requires sorted data or monotonic conditions
- Common bug: wrong midpoint or bounds updates
