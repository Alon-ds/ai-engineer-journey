# Hashmaps

## Topic

Hash maps store key-value pairs and support efficient lookup, insertion, and deletion.

## Common Patterns

- Frequency counting
- Lookup tables
- Grouping by key
- Sets and maps for membership checks

## Complexity Tips

- Average O(1) lookups and updates
- Worst-case hash collisions can degrade performance
- Use hashing strategically for high-speed checks

## Common Interview Questions

- Two Sum
- Top K Frequent Elements
- Isomorphic Strings
- Valid Sudoku
- Group Anagrams
