# Linked Lists

## Topic

Linked lists model nodes with pointers and are useful for understanding dynamic memory and traversal patterns.

## Common Patterns

- Dummy nodes
- Fast/slow pointers
- Reversal
- Merging and partitioning

## Complexity Tips

- Insertion/deletion are O(1) if pointer known
- Traversal is O(n)
- Be careful with pointer mutations and cycle detection

## Common Interview Questions

- Reverse Linked List
- Merge Two Sorted Lists
- Detect Cycle
- Remove Nth Node From End
- Intersection of Two Linked Lists
