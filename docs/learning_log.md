# Learning Log

This document is used to track learning progress, topics studied, and reflection notes.

## Weekly Reflection Template

- What did I learn this week?
- What was difficult?
- What code did I write?
- What should I improve next week?
- Which topics are still unclear?

## Example

```text
Week 1:
- Learned Python basics and virtual environment setup
- Reviewed Git workflow and commit hygiene
- Started DSA warm-up with arrays and strings
- Next steps: complete two more projects and improve note quality
```
