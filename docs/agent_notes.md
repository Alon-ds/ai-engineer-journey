# Agent Notes

## What is an AI Agent?

An AI agent combines:

- a language model
- tools or external actions
- reasoning and planning
- memory or state

## Typical Agent Loop

1. Receive task
2. Decide on tool use
3. Gather information
4. Reason about next steps
5. Return final answer or action

## Design Recommendations

- Keep tool boundaries clear
- Control agent autonomy carefully
- Add logging and observability
- Validate tool outputs
