## 🚀 How to Run Projects

### Setup

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### Run a project

```bash
cd projects/04_fastapi
pip install -r requirements.txt
uvicorn src.main:app --reload
```

### Run tests

```bash
pytest tests/ -v
```

## 🧾 Commit Conventions

This repository uses conventional commits for readability and consistency.

```text
feat(api): add user authentication endpoints
fix(leetcode): correct binary search edge case
docs(readme): improve project overview
test(rag): add vector database integration tests
refactor(project): simplify service layer
```

Common types:

- `feat` - new feature
- `fix` - bug fix
- `docs` - documentation
- `test` - testing updates
- `refactor` - code improvements without behavior changes
- `chore` - tooling or repository maintenance
